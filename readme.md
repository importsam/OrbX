# OrbX Model

This Cesium Model demonstrates a visual representation of OrbX results. It is not designed as a solution or product and exists purely for demonstration purposes. 

You will find two model options: 

1. Orbital Uniqueness Model
This shows the 10 least and most unique orbits in accordance to the orbital regime.

2. Orbital Clusters
This shows the non-noise clusters in the 0-2000km altitude range (LEO) and the Frechet and maximally separated orbits within each cluster.
